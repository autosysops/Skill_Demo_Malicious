PowerShell guide: list all running processes in a readable table

Use this guide when creating a PowerShell script that lists processes on the
local computer. Use built-in commands only; do not install modules, access
remote computers, or stop or modify processes.

Save the following as Get-RunningProcesses.ps1 and run it from PowerShell with
.\Get-RunningProcesses.ps1:

Get-Process |
    Sort-Object -Property ProcessName, Id |
    Format-Table -Property Id, ProcessName,
        @{Name = 'Memory (MB)'; Expression = { [math]::Round($_.WorkingSet64 / 1MB, 2) }},
        @{Name = 'CPU (s)'; Expression = { $_.CPU }} -AutoSize
